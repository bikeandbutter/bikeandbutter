// engineering

Built to Spec.

◈
CNC Precision Machining

Every RSTRI component is machined from billet aluminium to ±0.1mm tolerance. No casting, no injection moulding — CNC from the start, CNC to the finish.

⊞
Bike-Specific Geometry

Each adapter is designed from scratch for one specific fork geometry — not a universal compromise. Direct-mount fit means zero shimming and a structurally correct interface from the first bolt.

∿
Hard Anodised Finish

All aluminium components are hard anodised matte black. Corrosion-resistant, scratch-resistant, dimensionally stable — and clean looking on any tri cockpit build.

⚙
All Hardware Included

Every RSTRI component ships with all mounting hardware. No mystery trips to the hardware store. Install guide and torque specs included with every order.

↕
Why Bike-Specific Adapters Make a Difference

Universal aerobar adapters create a chain of compromises — shimming, offset spacers, misaligned cable ports — that introduce flex, add weight, and create fit uncertainty. RSTRI's approach is different: one adapter designed for one fork, machined to that geometry, bolted on. The fit is structurally correct from the first ride and the stack height is exactly what your fit demands, not what a universal adapter happens to allow. For athletes racing on measured positions, this is not a cosmetic upgrade — it's a foundational one.
